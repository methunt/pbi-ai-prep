## 4 · Implemented behaviors & microcopy
- Selection: checkbox toggles; Shift+click range-fills within CURRENT PAGE only; Space toggles when focus in tr[data-row] non-INPUT (preventDefault); Shift tracked via global keydown/keyup; 'Select all N matching' checks ALL matching across pages, indeterminate when partial; 'Clear' empties; persists across filter/search/page (Set of model indexes); overflow surfaced as '<N> outside current filter'.
- Pagination: 50/page; pager ≤7 pages full, else '1 … window(page±1, edges) … last'; '‹'/'›' disabled at ends; 'Showing <from>–<to> of <N>'.
- Sorting: header click; same key toggles, new key asc; page resets 1; '▲'/'▼'; ties by model order.
- Filters/search: 'all' | 'empty' | 'unused' via chip .on; search lowercase substring name+table+desc+dax; both reset page 1. 'All types', 'All tables', 'Reset view' NO handlers.
- Tabs: setTab toggles .on; AI sub-tabs setAiSub; row lineage icon → gotoLineage sets focus chip '<Table>[<Name>]' + switches 'lin'.
- Bulk: 'Include in AI'/'Exclude from AI' set .ai (non-Table) + pending += selection; 'Hide in model' sets .hidden flag never rendered; renames/desc/delete open modals.
- Rename pipeline: find/replace → strip prefix/suffix → underscores→spaces → Title Case → whitespace collapse; live preview; staged renames fill 'Rename to'; pending += changed.
- Delete: confirm splices rows out of MODEL; orphans added to pending (min(2, n) if checkbox kept).
- Pending dialog = hardcoded 6-row demo; 'Save'/'Save all changes' only closeModal — no persistence.
- AI schema: switch toggles .ai; per-table/global include/exclude; 'Expand all'/'Collapse all'; aiSearch auto-expands; synDel marks 'Deleted'; synAdd appends 'new term N' as 'User', cap 20.
- Char budget: 'Copy prompt' swaps to 'Copied — 54 included objects' 2100ms — NO clipboard API; counter syncs KPI; bar chars/100, red above 10,000.
- Parse animation: 4 stages tick 190ms ceil(target/7); emerald check dots; 420ms → app.
- Landing: 'Open PBIP folder' + Recent cards call startParse() — no real picker.
